# CODA-Net Execution Guide (A-Z)

This guide outlines the complete end-to-end execution of the CODA-Net framework, including all 5 ablation phases and the final table generation. 

---

## 🛑 PRE-REQUISITES: Code Changes Before Running Anything

Before you run the first command, you MUST update the dataset paths in `main.py`.

**File to edit:** `main.py` (At the very bottom, inside the `if __name__ == '__main__':` block)
**What to change:** Find the `data_paths` dictionary and update the string paths to point to your actual dataset folders on your machine/cluster.

```python
    # Update these paths to match your local dataset structure!
    data_paths = {
        'train_csv': 'data/aptos/train.csv',
        'train_img': 'data/aptos/train_images/',
        'val_csv': 'data/aptos/val.csv',
        'val_img': 'data/aptos/val_images/',
        'ext_csv': 'data/messidor/messidor_data.csv',
        'ext_img': 'data/messidor/images/',
        'style_pool_img': '' # Will be set dynamically by the code
    }
```
*Note: You do not need to change any other code for the rest of the pipeline. Everything is controlled via the terminal arguments below.*

## Phase 1: The Baseline Plateau (Table 1)
**Goal:** Find the best performing backbone architecture without any of our novelties.
**Command:** Run the following 10 commands one by one (or in parallel on different GPUs).

```bash
python main.py --mode baseline --model_name swinv2_l --exp_name baseline_swinv2_l
python main.py --mode baseline --model_name convnextv2_l --exp_name baseline_convnextv2_l
python main.py --mode baseline --model_name resnet50 --exp_name baseline_resnet50
python main.py --mode baseline --model_name efficientnetv2_m --exp_name baseline_efficientnetv2_m
python main.py --mode baseline --model_name mobilenetv3_l --exp_name baseline_mobilenetv3_l
python main.py --mode baseline --model_name maxvit_l --exp_name baseline_maxvit_l
python main.py --mode baseline --model_name densenet121 --exp_name baseline_densenet121
python main.py --mode baseline --model_name regnety_120 --exp_name baseline_regnety_120
python main.py --mode baseline --model_name vgg16_bn --exp_name baseline_vgg16_bn
python main.py --mode baseline --model_name squeezenet1_1 --exp_name baseline_squeezenet1_1
```
**Action After Phase 1:** Check the `results/baseline_*/tables/metrics_summary.csv` files. Find the model with the highest QWK. 
*For the rest of this guide, replace `<WINNER>` with your winning model's name (e.g., `convnextv2_l`).*

## Phase 2: SSL Pretraining Impact (Table 2)
**Goal:** Prove that EyePACS Lesion-Aware SSL initializes the weights better than ImageNet.
**Command:** Run these 5 commands to ablate the SSL components.

```bash
# 1. ImageNet Weights (No SSL)
python main.py --mode coda_net --backbone <WINNER> --exp_name ablation_ssl_imagenet

# 2. EyePACS Supervised Only
python main.py --mode coda_net --backbone <WINNER> --ssl_weights checkpoints/eyepacs_supervised_backbone.pth --exp_name ablation_ssl_supervised

# 3. Contrastive SSL Only
python main.py --mode coda_net --backbone <WINNER> --ssl_weights checkpoints/ssl_contrastive_only/ssl_pretrained_backbone.pth --exp_name ablation_ssl_contrastive

# 4. Multitask SSL Only
python main.py --mode coda_net --backbone <WINNER> --ssl_weights checkpoints/ssl_multitask_only/ssl_pretrained_backbone.pth --exp_name ablation_ssl_multitask

# 5. Full SSL (Lesion-Aware Contrastive + Multitask)
python main.py --mode coda_net --backbone <WINNER> --ssl_weights checkpoints/ssl_pretrained_backbone.pth --exp_name ablation_ssl_full
```
*Note: The `ablation_ssl_full` run acts as the "Standard Cross-Entropy" baseline for the next phase.*

---

## Phase 3: Label Noise & Imbalance Resolution (Table 3)
**Goal:** Prove that Confident Learning (CL) breaks the 85% plateau better than traditional imbalance methods (LDAM+DRW).
**Command:** Run these 2 commands (the 3rd row of Table 3 is already generated by `ablation_ssl_full`).

```bash
# 1. Traditional Imbalance Baseline (LDAM Loss + Deferred Re-Weighting)
python main.py --mode baseline --model_name <WINNER> --loss_type ldam --use_drw --exp_name ablation_ldam_drw

# 2. Proposed Confident Learning (Cleans human label noise)
python main.py --mode coda_net --backbone <WINNER> --ssl_weights checkpoints/ssl_pretrained_backbone.pth --use_cl --exp_name ablation_noise_cleaned
```

---

## Phase 4: Grade Boundary Resolution (Table 4)
**Goal:** Prove that Ordinal Contrastive Loss improves adjacent-grade accuracy (QWK) over standard Cross-Entropy.
**Command:** Run this command (the Cross-Entropy baseline is already generated by `ablation_noise_cleaned`).

```bash
# 1. Proposed Ordinal Contrastive Loss
python main.py --mode coda_net --backbone <WINNER> --ssl_weights checkpoints/ssl_pretrained_backbone.pth --use_cl --use_ordinal --exp_name ablation_loss_ordinal
```

---

## Phase 5: Domain Generalization (Table 5)
**Goal:** Prove that Feature-Space MixStyle fixes the external accuracy drop on Messidor-2, and that Pixel-Space FDA fails due to Ben Graham filtering.
**Command:** Run these 3 commands.

```bash
# 1. No Domain Adaptation
python main.py --mode coda_net --backbone <WINNER> --ssl_weights checkpoints/ssl_pretrained_backbone.pth --use_cl --use_ordinal --domain_adapt none --exp_name ablation_domain_none

# 2. Pixel-Space FDA (The Baseline Bug)
python main.py --mode coda_net --backbone <WINNER> --ssl_weights checkpoints/ssl_pretrained_backbone.pth --use_cl --use_ordinal --domain_adapt fda --exp_name ablation_domain_fda

# 3. Feature-Space MixStyle (The Proposed Fix & Final CODA-Net Model)
# NOTE: --style_source both will automatically run two experiments: one with EyePACS (DG) and one with Messidor (UDA).
python main.py --mode coda_net --backbone <WINNER> --ssl_weights checkpoints/ssl_pretrained_backbone.pth --use_cl --use_ordinal --domain_adapt mixstyle --style_source both --exp_name ablation_domain_mixstyle
```
